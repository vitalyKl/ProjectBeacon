# R1.2 — Split WorkstationActions

## Goal

Split `ProjectBeacon.Cli/Client/WorkstationActions.cs` by responsibility.

## Target groups

- filesystem/project initialization;
- Git helpers;
- evaluation/review;
- OpenCode actions;
- MCP config manipulation;
- process/probe helpers.

Suggested files:
- `FileSystemActions.cs`
- `GitActions.cs`
- `EvalActions.cs`
- `OpenCodeActions.cs`
- `McpConfigActions.cs`
- `ProcessActions.cs`
- `WorkstationProbe.cs`

Keep the existing public behavior and contracts.

Do not change:
- Eval semantics;
- OpenCode protocol;
- daemon packaging;
- MCP schema;
- path-security policy.

Run affected tests, full suite, and format verification.
