# R1.5 — Split WorkstationDaemon

## Goal

Reduce `WorkstationDaemon.cs` into explicit responsibilities without implementing H5.

## Target groups

- daemon lifecycle/orchestration;
- heartbeat loop;
- command loop;
- llama synchronization;
- runtime/state publication.

Suggested files:
- `WorkstationDaemon.cs`
- `DaemonHeartbeatLoop.cs`
- `DaemonCommandLoop.cs`
- `DaemonLlamaSync.cs`
- `DaemonRuntimeState.cs`

Keep existing runtime behavior.

Do NOT:
- introduce per-project runtime isolation;
- redesign runtime ownership;
- change heartbeat/command semantics.

Those belong to H5/H8.
