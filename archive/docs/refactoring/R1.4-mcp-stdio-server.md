# R1.4 — Split McpStdioServer

## Goal

Separate transport, routing, scope, parsing, and formatting responsibilities in `McpStdioServer.cs`.

## Target structure

- `McpStdioServer.cs` — transport/lifecycle;
- `McpToolRouter.cs` — routing;
- `McpSessionScope.cs` — scope/session rules;
- `McpArgumentParser.cs` — argument parsing;
- `McpResultFormatter.cs` — result/error formatting;
- `McpLocalTools.cs` — local tools;
- `McpApiToolAdapter.cs` — API-backed tools.

Keep the stdio protocol unchanged.

Do not redesign authorization or local MCP security here.
Do not change tool schemas.

Run MCP tests, full suite, and formatting.
