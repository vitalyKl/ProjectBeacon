# R1.7 — Split EF Model Configuration

## Goal

Reduce the size of `BeaconDbContext.OnModelCreating`.

Use `IEntityTypeConfiguration<T>` classes grouped by domain.

Possible areas:
- users/auth;
- projects/membership;
- tasks/pipeline;
- devices/runtime;
- agents/models;
- chat;
- eval/review;
- context.

Keep `BeaconDbContext` responsible for:
- DbSets;
- configuration registration;
- global EF behavior.

Do not modify the database model intentionally.
Do not edit generated migrations/snapshots.

Run:
- EF model check;
- full tests;
- formatting.
